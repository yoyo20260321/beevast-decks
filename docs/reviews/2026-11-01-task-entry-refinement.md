# 任务入口与口径调整

来源：admin5建议“范围任务”改“全部任务”，需求/任务切换入口放执行任务card。

- 全部任务卡保持全局计数、全局可筛选列表；单纯打开列表不改变地图当前聚焦。范围内任务计数不再冒充全部。
- 执行任务卡保留当前视角执行任务数，标下拉入口；打开后可按需求或任务聚焦，也可进入当前视角执行列表。
- 战场不重复设置视角选择入口；聚焦时保留“返回全局”，标出当前需求/任务。
- 全局列表与当前视角列表在标题/匹配总数中明确区分，既有决定/准入/执行模型不改。

验证：既有69模型用例、9视口布局与桌面/手机作业路径；额外检查聚焦REQ-101时全部任务仍7条且地图保持REQ-101，SIM201聚焦时执行列表仅1条。
