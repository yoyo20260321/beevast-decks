# 智能客服工作台「石墨墨玉」视觉升级规格

日期：2026-09-24  
目标页面：`demos/scenario-1-cs.html`  
已确认方向：A · 石墨墨玉

## 1. 目标与边界

在不改变现有业务结构、功能与示意数据的前提下，将页面从“通用浅色 SaaS 后台”升级为具有品牌记忆、材质层次和专业可信感的高端企业工作台。保留会话、语言切换、发送、转人工、建单、数据分析及响应式交互。

本次不增加新业务功能、不接入外部资源、不修改 GitHub Pages 路径。

## 2. 视觉系统

- 主画布采用偏暖瓷白，消除大面积冷灰造成的廉价感。
- 导航采用深石墨色，内容面使用暖白与浅石色，通过色温差而非重边框分区。
- 墨玉绿是唯一核心交互色，用于当前导航、主按钮、选中态、焦点态与关键数据。
- 香槟金仅用于 BeeVast 品牌标识、少量关键标签或强调线，禁止大面积铺色。
- 风险、成功、等待仍使用红、绿、琥珀语义色；颜色必须与文字或图标共同表达状态。
- 字体继续使用系统字体栈；加强数字与标题字重，正文保持舒适、克制。
- 卡片减少可见边框，主要依靠留白、细分割线、轻微色面和低扩散阴影建立层次。
- 圆角统一收紧：主面板 10–12px，控件 6–8px，胶囊只用于短标签。

## 3. 核心区域处理

1. 顶栏：品牌区域加入克制的香槟金标识；语言、在线状态和建单按钮重新分级，避免所有控件同权。
2. 左侧导航：石墨底、低对比默认项；当前项采用深墨玉色面与金色细标记，替代普通灰色高亮。
3. 会话列表：默认项弱化边框；当前会话使用暖墨玉浅色面与明确的左侧状态标识。
4. 消息区：暖石色背景承托暖白消息卡；客户消息使用浅墨玉色面，系统事件保留审计时间线形态。
5. 证据栏：从三张同权卡片调整为一条紧凑证据带，风险项以文字和细色标强调，不制造“AI 卡片墙”。
6. AI 草稿：作为主操作前的审核面板，使用暖白实体面、墨玉左标、来源和置信度分层展示；不使用发光、虚线或渐变。
7. 右侧上下文：使用分组标题、数据行和少量浅色面，降低嵌套卡片感；关键数字加强字重。
8. 数据分析：继承同一色板；主序列墨玉绿，辅助序列低饱和蓝灰，强调数据可读性而非装饰。
9. 弹层与提示：暖白面板、石墨标题、柔和遮罩；焦点和完成状态统一使用墨玉色系统。

## 4. 交互与响应式

- 保持现有发送、转人工、建单、会话切换、分析筛选等行为不变。
- hover 仅做轻微色面与边框变化，不使用漂浮或缩放式“炫技”动画。
- 保持清晰可见的键盘焦点、禁用态和异步反馈；遵循 `prefers-reduced-motion`。
- 1440×900、1024×768、390×844 三档不得出现遮挡、横向溢出或主要操作不可达。
- 小屏仍以会话和编辑器为主，上下文使用抽屉；视觉色板与层级保持一致。

## 5. 验收标准

- 页面不再出现大面积冷灰与通用青绿组合，四个核心色角色明确：石墨、瓷白、墨玉、香槟金。
- 品牌金只作点睛，不能与主操作争抢注意力。
- 首屏主视觉顺序清晰：当前会话 → 客户问题 → 证据/风险 → 草稿 → 审核发送。
- 主要文字与背景对比度达到 WCAG AA；交互控件边界可识别。
- 三档截图检查通过；核心交互回归通过；控制台无阻断错误。
- 页内版本标识更新，并在合并 `main` 后验证公网 URL 返回 200、展示新视觉版本。

## 6. 明确放弃

- 放弃纯黑、霓虹、光晕和高饱和渐变，避免回到“AI 驾驶舱”。
- 放弃全局金色装饰，换取克制与可信。
- 放弃通过大量边框制造层级，改用色温、留白和排版。
- 放弃改动业务架构和数据结构，确保本轮升级聚焦视觉品质且易于回退。
