# 人机协作地图五项产品优化（Mock）

来源：admin5批准全部落实产品评审五项建议；不增加真实系统接入、持久化或平台角色调度。

采用原单HTML与单状态模型增量实现；放弃重建页面/新增图表依赖，以保持现有一屏及准入保护。

1. 决策：每任务有固定版本的mock目标、范围、AC与风险，证据详情展示逐条结果/版本；新建默认登记草稿，可填写目标/范围/AC并显式提交范围批准；空材料不能批准。现有任务metadata编辑不改语义；确认/质量退回/业务验收退回须输入理由，提交时校验阶段、版本与证据门；理由进入任务事件。失联核对不混入业务决定。
2. 筛选：关键词常显，高级8维筛选折叠，常用视图（待人/异常/即将到期）与已选条件可删除，匹配数和清空入口明显。即将到期明确参照固定演示日期2026-11-01，7日内且未关单。360x640首屏显示完整任务卡，主触点>=40px。筛选与草稿跨刷新保持。
3. 对象：推荐行动与选中任务视觉独立，主按钮标任务号，故障注入收进演示控制，详情/地图/证据保持同任务。
4. 曲线：保存最近60模拟秒的不可变快照（状态分类、任务ID、事件文本）；点击打开曲线回看，能选择真实存在时点、看值/资源阈值与等待分类/关联事件/当时任务，并明确跳转是查看任务当前状态。冻结回看时点不停止全局模拟，快照不随当前状态变化；无事件明确无记录，不伪造归因。
5. 结果：确认→交接/归档→已关单说明下一责任人及播放/暂停推进条件；处理后空列表显示最近处理结果及返回任务入口；通知只显示一次。

验证：保留原54模型用例与9视口回归；新增草稿/提交/理由/版本拒绝/历史快照/即将到期测试，浏览器实测证据展开、理由表单、手机折叠筛选和40px、常用视图、曲线回看、处理反馈/空列表；独立产品复测与质量审查后原公网地址原子替换并读回哈希。
