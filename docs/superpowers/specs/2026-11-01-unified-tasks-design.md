# 统一任务树 Demo（已获用户方案批准）
统一任务对象，类型：项目／迭代、功能需求、缺陷、改进、工程任务、调研验证。父子关系表示拆解，依赖单独记录。PRD是关联材料。
生命周期：草稿→待确认→已就绪→进行中→待关单→已关单；取消中→已取消；重开留理由、增加版本并回待确认。
阶段：需求、计划、开发、测试／审查、合并、发布、验收、关单；按完成层级明确适用门，不自动跳门。
信号：执行中、排队、待补材料、依赖阻塞、待人决定、已暂停、执行状态未知，可多选。
制作独立 task-tree-demo.html 并从原地图可访问，使用10个任务（包括父任务），覆盖六种类型、全部生命周期和典型信号。树形／列表共用数据、筛选、选中。筛选保留祖先，不把祖先计入匹配数。详情含目标、AC、计划、依赖、执行和证据、模拟处理。取消须先核对执行终态；父任务关单须全部子任务关单及自身验收。页面内存Mock，重置恢复，不影响平台。
桌面单屏，树区内部滚动；移动自适应，详情使用弹窗。浏览器核验树、筛选、祖先、详情、模拟决策、取消、重开、父关单门。
