# 关单信息合并与最长等待提醒

admin5同意：关单累计与顶部卡重复，合并上方并改名，底部换最长阻塞/最久待人决定。

- 顶部“已关单任务”统一全局数量，与“全部任务”同口径；点击全局已关单列表，显示记录的关单时间，累计趋势折叠在弹窗中（近60模拟秒），不在首页重复展示。模拟属性沿用统一页面标识。不把子任务关单当需求验收。
- 底部第三块“全局·最长阻塞 / 最久待人决定”展示当前仍未解除的两类最长连续时长与任务入口。空集合显示“无阻塞/无需决定”，刚开始显示0模拟秒；首次观测时间不明不编造时长。点击按时长下探原因、处理方、影响与任务处理。
- 时间口径：从本页首次观测进入该类等待起，以模拟时钟计；同任务同类等待的原因变更不重置，完全解除后再发生重新计时。阻塞类与待处理原分类一致；未知状态在问题入口，不冒充资源等待。暂停/断线冻结模拟时长并明确过期，不当真实墙钟。
- 全局提醒/关单总数不随地图聚焦改变；现有全部任务/执行卡入口不变。关单列表过滤固定done，可组合关键词/项目等；趋势折叠状态、表单草稿跨tick保持。
- 一并修正资源图“等待不计槽”的绝对说明，未准入排队不占槽，未知/执行中受阻可保留占用。
